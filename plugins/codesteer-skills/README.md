# codesteer-skills

> Gerado por `pnpm build:plugin` a partir de `packages/skills-catalog/skills/`. Não edite esta pasta à mão.

Catálogo codesteer de skills para agentes de IA: arquitetura, automação, criativo, frontend, marketing, produto, engenharia de prompt, segurança e testes.

| Plataforma | Instalação |
|---|---|
| Claude Code | `/plugin marketplace add LuisCarlosLopes/codesteer-agent-skills` → `/plugin install codesteer-skills@codesteer` |
| OpenAI Codex | `codex plugin marketplace add LuisCarlosLopes/codesteer-agent-skills` → `codex plugin add codesteer-skills@codesteer` |
| GitHub Copilot CLI | `copilot plugin marketplace add LuisCarlosLopes/codesteer-agent-skills` → `copilot plugin install codesteer-skills@codesteer` |
| VS Code (Copilot) | `chat.plugins.marketplaces`: `["LuisCarlosLopes/codesteer-agent-skills"]` |
| Cursor | Customize → Plugins → From GitHub Repository → `https://github.com/LuisCarlosLopes/codesteer-agent-skills` |
| Gemini CLI | `gemini extensions install https://github.com/LuisCarlosLopes/codesteer-agent-skills` (usa o archive do GitHub Release) |
| Antigravity | `agy plugin install <clone>/plugins/codesteer-skills` |
