# Template B — Character + Campaign Context

Personagem inserido em contexto de marca. Use quando houver setor, público-alvo ou linguagem visual de marca definidos. Prompt final: 400-600 palavras em inglês.

```
[TASK]
Generate an ultra-realistic photographic portrait of a [gender] character for a [tipo de campanha] campaign.

[BRAND CONTEXT]
Brand/Sector: [nome ou setor, posicionamento].
Target audience: [demográfico + psicográfico].
Campaign emotion: [1-3 emoções-alvo: empowerment, trust, warmth, aspiration].
Visual language: [referência de marca ou estilo, ex.: "Apple minimalism", "Nike bold storytelling"].

[CHARACTER — Full Anatomical Profile]
1. Identity: [gênero], [idade aparente], [etnia], [tom de pele Fitzpatrick + undertone].
2. Face: [formato + estrutura óssea + detalhes de olhos, nariz, lábios; mínimo 3 linhas].
3. Skin: [textura com imperfeições naturais: poros, sardas, marcas, peach fuzz, subsurface scattering].
4. Hair: [tipo, cor com reflexos, comprimento, estilo, textura, comportamento com luz].
5. Expression: [micro-expressão + direção do olhar + emoção transmitida].
6. Body: [biotipo, postura, linguagem corporal, posição das mãos].
7. Wardrobe: [vestuário com cor, tecido, caimento + acessórios com material].

[SCENE COMPOSITION]
- Framing: [close-up, medium, full body + regra dos terços].
- Background: [cenário com camadas de profundidade].
- Foreground elements: [objetos, partículas, desfoque, se houver].

[CINEMATOGRAPHY]
[Prompt Injection da direção escolhida em references/cinematic-directions.md]

[OUTPUT]
Resolution: [2K|4K] | Ratio: [16:9|9:16|1:1|4:5|2:3] | Preset: realistic
Negative: [Negative Injection contextual]
```

Para crianças, insira a injection de `references/child-characters.md` no item 1 e anexe a negative adicional.
