# Mini-template reutilizável (seção 10 da saída)

Entregue ao final de cada campanha uma versão deste bloco, com os campos vazios ou pré-preenchidos com exemplos do segmento atual. O usuário deve conseguir gerar um novo roteiro apenas preenchendo os campos.

```text
Gere uma campanha para Reels/TikTok seguindo o processo do Gerador de Campanha
(diagnóstico → estratégia → 3 ângulos → melhor caminho → roteiro → cena a cena →
variações → adaptação por canal → execução → prompt reutilizável).

- Produto / serviço / app:
- Público-alvo (quem, momento de vida, contexto de uso):
- Problema que resolve:
- Diferencial competitivo:
- Benefício principal (em uma frase simples):
- Objeções mais comuns do público:
- Objetivo da campanha (download / lead / venda / seguir / tráfego):
- Oferta (o que, condição, prazo):
- Tom desejado:
- Canal (Reels / TikTok / ambos):
- Duração aproximada:
- Provas disponíveis (números, depoimentos, demonstrações, antes/depois):
- O que NÃO dizer (claims proibidos, concorrentes, termos a evitar):

Se algum campo ficar vazio, assuma o mais plausível, sinalize a suposição e avance.
```

**Uso:** copie o bloco, preencha os campos e envie junto com a skill ativa.
