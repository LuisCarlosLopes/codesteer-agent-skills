# Contribuições

Este repositório está **aberto para uso** e **fechado para contribuições** neste momento.

## O que você pode fazer

O código e as skills estão sob [Apache License 2.0](LICENSE). Você pode usar, copiar, modificar e distribuir o material — inclusive em produtos comerciais — desde que preserve a licença e os avisos de copyright.

Não é preciso abrir issue nem pedir permissão para isso.

## O que ainda não é aceito

- Issues
- Pull requests de forks
- Patches, novas skills ou correções enviadas por terceiros

Issues estão desativadas. PRs vindos de forks são fechados automaticamente.

Quando as contribuições forem abertas, este arquivo será atualizado com o fluxo (formato canônico, gates de CI e revisão).

## Maintainer

Quem tem write no repositório continua trabalhando por branches internas e PRs no próprio remoto — o bloqueio vale para contribuição externa.
